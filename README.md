# Proyecto: Base de Datos "ZOO Taller"

Diseño e implementación de una base de datos relacional para administrar facturas, órdenes de pago y la información relacionada con la reparación de vehículos en distintas sucursales. Este sistema permite optimizar el servicio mediante el registro detallado de clientes, vehículos y los mecánicos asignados a cada orden de trabajo.

## Documentación y Estructura

*   **`Proyecto_FINAL_PDF_BD_ZOO_TALLER.pdf`**: Documentación técnica detallada del sistema. Incluye el documento de requerimientos, el Diagrama Entidad Relación (DER), el Modelo Lógico Relacional (MLR), el diccionario de datos y las consultas SQL de prueba.
*   **`script_zoo_taller.sql`**: Script DDL principal para la creación de las tablas del sistema (`cliente`, `vehiculo`, `sucursal`, `mecanico`, `ord_tra`, `ord_pago`, `factura`, etc.) y sus relaciones.
*   **`CREATE DATABASE zoo taller.txt`**: Archivo de soporte con comandos iniciales.

## Herramientas y Tecnologías

*   **Lenguaje:** SQL
*   **Sistema Gestor de Bases de Datos:** MariaDB.
